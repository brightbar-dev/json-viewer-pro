Local files

Browsers only let an extension read file:// pages if you allow it. In Chrome:

  1. Copy this address: chrome://extensions
  2. Paste it into the address bar and press Enter. Extension pages cannot open that address for you.
  3. Turn on Allow access to file URLs.

Or skip that entirely: open the viewer page and drop the file on it.

Private, and verifiably so

No analytics, no ads, no donation popups, and no network requests of its own. The only permission is storage, for your settings. Every build is checked automatically for any code that could send data anywhere, and fails if it finds some. The check is open source on GitHub.
